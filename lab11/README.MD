# Credit Card Customer Segmentation

This project uses K-Means clustering to segment credit card customers based on their spending behavior and financial activity.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Project Steps

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Feature scaling using StandardScaler
* Finding the optimal number of clusters
* Applying K-Means clustering
* Visualizing customer segments

## Results

The model successfully grouped customers into different segments based on their behavior, which can help businesses improve marketing strategies and customer understanding.
